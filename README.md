# @sellgar/pagination

Общая курсорная пагинация Sellgar backend. Node 24+, PostgreSQL, TypeORM 1.x.

Запрос: `{ limit?: number, nextToken?: string, ...filters }`; default 50, maximum 100.
Ответ: `{ data: T[], meta: { limit, nextToken: string | null } }`.
COUNT не выполняется. Подсчёт количества не входит в списочный контракт или
в библиотеку; отдельные read models для него будут проектироваться независимо.
Отсутствие продолжения обозначается только `nextToken: null`.

`CursorQueryDto` — базовый DTO списочного endpoint. `offset` отклоняется.
`CursorMetaEntity` — общая валидируемая форма метаданных.

`CursorPagination.read(query, request, { scope, filters, order })` получает
отфильтрованный QueryBuilder без limit/offset, стабильный endpoint scope и
нормализованные фильтры без limit/nextToken. order задаётся кодом владельца;
последний ключ — первичный ключ корневой сущности. Nullable-ключи не поддерживаются.
Поисковый rank допускается как SQL expression с типом real.

Библиотека читает limit+1 уникальных ключей корня, затем загружает только выбранные
агрегаты с relations. Она не обрезает строки JOIN и не читает всю коллекцию.
Даты и числовые ключи берутся как SQL text, сохраняя микросекунды/точность БД.

Токен — внутренний URL-safe continuation bookmark. Клиенты хранят и передают его
целиком; его схема не является публичным API и может меняться. Он связан с scope,
сортировкой и фильтрами, но не является credential и не заменяет auth-предикаты.
Токен не хранит SQL или предоставленные клиентом выражения сортировки.

Пагинация не фиксирует снимок коллекции между HTTP-запросами. Удаление граничной
записи не мешает продолжению; вставки до курсора не повторяют прошлую страницу.
Изменение ключа сортировки у существующей записи может переместить её; для обычных
списков следует выбирать неизменяемые created_at/uuid/code. При необходимости
согласованного чтения одной страницы caller использует свою транзакцию.

При отдельном checkout используется Yarn 4 через Corepack; внутри сервиса — его Yarn workspace.
Проверки: `corepack yarn build && corepack yarn test`. DB-набор включается переменной
`PAGINATION_TEST_DATABASE_URL` и работает только во временной схеме.
